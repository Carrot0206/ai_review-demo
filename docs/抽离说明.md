# 抽离说明

规则库页面、规则库API、Excel导入逻辑、测试和现有规则数据已经从审核Demo迁入本项目。

原审核Demo不再注册 `/api/rule-library`，前端也不再判断 `/rule-library` 路径。部署时由外层Nginx保持原URL不变：

- `/` 和原审核API继续指向 `trust-ai-review-demo`。
- `/rule-library/` 指向本项目的前端构建产物。
- `/api/rule-library/` 指向本项目后端。
- `/api/rule-engine/` 预留给后续规则引擎审核API。

当前 `rules.json` 是抽离时规则库的完整数据快照。后续建议把它放到程序目录之外的持久化目录，并通过 `RULE_LIBRARY_FILE` 配置路径。
